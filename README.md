# Bahamas Solidário

## Atualização visual Bento

O estilo da referência foi aplicado a todas as páginas e aos componentes existentes:
fundo claro, cartões arredondados, azul (#271d67 e #526db7), vermelho (#e51a26), branco, fontes Geist
e Geist Mono, grades responsivas e formulários com o mesmo acabamento visual.
O tema está em `src/bento-theme.css`.

As páginas Visão geral, Campanhas, Doações, Necessidades e Relatórios continuam
com os dados, cálculos, filtros, cadastros, exportações, compartilhamento e
notificações originais. Não há carteira cripto ou novos dados demonstrativos.
O armazenamento continua usando a chave `bs-demo`, preservando os registros
do navegador quando o site é acessado na mesma origem (protocolo, domínio e porta).
O modo claro é o padrão, seguindo a identidade visual original; preferências
salvas e a opção de alternar para o modo claro são mantidas.

Sistema de gestão de campanhas solidárias do Grupo Bahamas.

## 🚀 Início Rápido

### Instalação
```bash
npm install
```

### Desenvolvimento
```bash
npm run dev
```
Acesse: http://localhost:5173

### Build para Produção
```bash
npm run build
```
