## 💡 Dicas de Uso

### 🔔 Notificações
- Verifique regularmente o sino de notificações
- Notificações destacam itens que precisam de atenção
- Use os alertas para priorizar campanhas urgentes

### 📊 Gráficos
- Gráficos são atualizados automaticamente
- Visualize tendências na página Visão Geral
- Use para identificar campanhas com mais engajamento

### 🔍 Filtros
- Combine múltiplos filtros para análises específicas
- Use ordenação para encontrar rapidamente o que precisa
- Filtros por data são úteis para relatórios periódicos

### 📤 Compartilhamento
- Compartilhe campanhas nas redes sociais
- Link direto pode ser enviado por WhatsApp/E-mail
- Aumente o alcance das campanhas

### 📥 Exportação
- **CSV**: Para análises em planilhas
- **HTML**: Para relatórios visuais e impressão
- **JSON**: Para backup e integração com outros sistemas

### 🌙 Modo Escuro
- Use à noite ou em ambientes com pouca luz
- Reduz fadiga ocular
- Economiza bateria em telas OLED

## ❓ Perguntas Frequentes

**P: As notificações aparecem automaticamente?**
R: Sim! O sistema verifica automaticamente o progresso das campanhas.

**P: Os dados são salvos?**
R: Sim, no navegador (localStorage). Para backup permanente, use exportação JSON.

**P: Posso usar em vários dispositivos?**
R: Atualmente os dados ficam no navegador. Use exportação/importação para sincronizar.

**P: O modo escuro funciona em todas as páginas?**
R: Sim! Todo o sistema tem suporte a modo escuro.

**P: Posso filtrar doações também?**
R: Atualmente apenas campanhas têm filtros avançados. Use a busca para doações.

## 🆘 Suporte

Problemas ou dúvidas?
1. Verifique se o navegador está atualizado
2. Limpe o cache se houver comportamento estranho
3. Faça backup dos dados (exportação JSON) antes de limpar dados
